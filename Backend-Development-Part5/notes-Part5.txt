 Question: 
 app.use(express.json());
app.use(express.urlencoded({ extended: true })); 

what is the use of these two lines of code in express.js?

 Full Explanation:
In Express.js, the lines of code `app.use(express.json())` and `app.use(express.urlencoded({ extended: true }))` are middleware functions that are used to parse incoming request bodies in different formats.
