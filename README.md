# 🚀 Backend Course — MERN Stack

A hands-on learning journey through **backend web development** — the server-side half of the MERN stack (MongoDB, Express.js, Node.js). This repository documents notes, exercises, projects, and code written while studying backend development from the ground up.

---

## 📖 About

This course covers everything needed to build robust, scalable server-side applications using:

- **Node.js** — JavaScript runtime for building server-side applications
- **Express.js** — Minimal and flexible web application framework for Node.js
- **MongoDB** — NoSQL database for storing application data
- **Mongoose** — Elegant MongoDB object modeling for Node.js

## ⚙️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/anasyousaf-dev/Backend-Course.git
   cd Backend-Course
   ```

2. **Install dependencies** (inside any project folder)
   ```bash
   npm install
   ```

3. **Set up environment variables**
   - Copy `.env.example` to `.env` and fill in your values (e.g., MongoDB URI, JWT secret).

4. **Run the development server**
   ```bash
   npm run dev
   ```
